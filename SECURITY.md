# Política de Segurança

Este projeto é uma Prova de Conceito (PoC) voltada estritamente para pesquisa educacional em engenharia reversa e proteção de software.

## Reportando Vulnerabilidades
Caso encontre falhas graves ou queira sugerir melhorias na lógica de evasão, sinta-se à vontade para:
1. Abrir uma **Issue** no repositório.
2. Entrar em contato via perfil do GitHub.

Não utilize este código para atividades maliciosas. O autor não se responsabiliza pelo uso indevido destas técnicas.
